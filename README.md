# 🎬 Movie Search App

Консольное приложение для поиска фильмов по базе данных **sakila** с логированием запросов.

## 🚀 Функциональность

- 🔍 Поиск фильмов по названию
- 🎭 Поиск по жанру и диапазону годов
- 📄 Пагинация (по 10 результатов)
- 📝 Сохранение поисковых запросов в MongoDB
- 📊 Топ-5 популярных запросов

## 🛠 Технологии

- Python
- MySQL (sakila database)
- MongoDB (Atlas)
- pymysql
- pymongo
- python-dotenv
- tabulate
- tkinter
